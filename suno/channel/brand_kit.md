## 새 채널 만들기 순서 (같은 구글 계정, 브랜드 계정)
1. 유튜브 앱 또는 웹 → 프로필 사진 → 설정 → 채널 추가 또는 관리 → 채널 만들기
2. 채널 이름: 33 at Night → 만들기
3. 핸들: @33atnight 입력 (사용 가능 여부가 바로 표시됨. 안 되면 @33atnight.fm 또는 @33atnightfm)
4. 스튜디오 → 맞춤설정 → 기본 정보: 위 '채널 소개' 붙여 넣기, 연락처 이메일 입력
5. 맞춤설정 → 브랜딩: 프로필 사진(레코드판+초승달 로고), 배너(문구: 판을 걸어 두는 밤)
6. 구글 계정 2단계 인증 켜기 (수익화 필수)
7. 첫 영상: Moody R&B 플리, 같은 날 훅 숏츠 1개

## 기존 채널 곡 재사용 규칙
- 직접 만든 곡이라 재조합해서 새 영상으로 쓰는 것 자체는 가능
- 단, 수익화하려면 곡을 만들 때 Suno Pro·Premier 구독 중이었어야 함 (무료 플랜 곡은 수익화 불가, 나중에 업그레이드해도 소급 안 됨)
- 같은 영상을 두 채널에 동시에 공개하지 않기 (옮기면 기존 채널 쪽은 비공개)
- 재조합할 때마다 선곡·순서·제목·썸네일·설명을 새로 (같은 곡 묶음을 순서만 바꿔 반복 업로드 금지, 유튜브 '반복·템플릿형 콘텐츠' 기준)
- 한 영상에서 새 곡 비중을 절반 이상으로 유지하는 것을 권장 (기존 곡은 '다시 듣기'처럼 일부만)
- 곡을 유통사로 음원 발매하고 Content ID까지 등록했다면, 내 채널에도 저작권 신고가 걸릴 수 있으니 채널을 예외 목록에 추가
