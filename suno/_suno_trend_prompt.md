## 1단계. 장르별 트렌드 조사 (장르마다 반복)

### 1-1. 최근 30일 반응 수집
- `last30days`로 장르마다 2번 돌린다.
  - 질문 A: `"<장르> music trends"` (예: `boom bap revival`, `k-pop new releases`)
  - 질문 B: `"suno <장르> prompt"` (Reddit r/SunoAI 등에서 실제로 잘 나온 스타일 표현 수집)
- 웹 검색으로 보완한다.
  - 최근 30일 차트·플레이리스트: Billboard, Spotify Viral 50, YouTube Music 인기, Melon·Genie(케이팝·발라드), TikTok 인기 사운드
  - 검색어 예: `<장르> trending songs November 2026`, `<genre> viral tiktok sound this month`
- 장르마다 **지금 뜨는 곡 5~10개**를 고른다. 곡 제목·발매일·어디서 뜨는지(차트 순위, 조회수, 틱톡 사용량)를 기록한다.

### 1-2. 대표곡 1~2곡 소리 분석 (가능할 때)
- 유튜브 링크가 있으면 오디오만 받아 로컬에서 분석하고 바로 지운다(기존 상시 허락 범위).
- 측정: BPM, 키(장·단조), 구조(후렴 첫 등장 시점, 곡 길이), 보컬 유무·음역, 저음 비중, 음량(LUFS).
- 가사는 분석만 하고 **절대 옮겨 적지 않는다.** 멜로디·훅 단어도 가져오지 않는다.

### 1-3. 트렌드 시트로 정리 (장르마다 세로 목록)
- 템포 범위: 예) 88~94 BPM, 하프타임 여부
- 키·조성: 단조/장조 비율, 많이 쓰는 키
- 드럼: 패턴(붐뱁 스윙, 트랩 하이햇 롤, 저지 바운스, 투스텝 등), 질감(드라이·타이트·라이브)
- 베이스: 808 / 신스 베이스 / 라이브 베이스, 길이와 글라이드
- 대표 악기: 2~4개 (예: 클린 일렉 기타 리프, 로즈, 샘플 찹, 스트링 스탭)
- 보컬: 싱잉랩 / 정박 랩 / 멜로디 / 톤(로우·미드, 허스키 여부), 더블링 여부
- 믹스: 깨끗함 vs 거침, 보컬 앞에 세우기 여부, 리버브 양
- 곡 길이·구조: 평균 길이, 후렴이 몇 초에 나오는지, 인트로 길이
- 가사 테마: 최근 많이 나오는 정서·상황 3개 (직설적인 단어 말고 "태도"로 요약)
- 제목 패턴: 한 단어, 숫자, 짧은 문장 등
- 출처: 각 항목 옆에 어디서 봤는지(플랫폼·날짜) 한 줄

## 2단계. 사운드를 Suno 스타일로 옮기기

### 공통 규칙 (모든 장르)
- 실존 가수·곡·프로듀서 이름 금지. "OO 스타일" 대신 소리 묘사로 바꾼다.
- 길이 **3분 내외(2:50~3:15)**. BPM으로 마디 수를 계산해 맞춘다(1마디 = 240 ÷ BPM 초).
- **곡 설계(필수 섹션)**: 모든 곡에 `사비(Chorus)` · `브릿지(Bridge)` · `핵사비(Final Hook Chorus)`가 반드시 들어간다. 섹션 순서·마디 수는 아래 "장르별 곡 설계"에서 장르에 맞게 고르고, 조사 결과(후렴 첫 등장 시점 등)에 맞춰 조정한 뒤 이유를 한 줄 쓴다.
  - **사비**: 곡의 훅 후렴. 첫 사비는 에너지 절반.
  - **브릿지**: 2절 뒤, 핵사비 바로 앞. 편곡을 빼거나 바꿔 대비를 만든다(드럼 빠짐·하프타임·악기 1~2개). 가사는 화자의 잘못된 믿음이 깨지는 순간(M4).
  - **핵사비**: 곡에서 가장 센 마지막 후렴. 사비 훅 첫 줄은 그대로, 편곡은 최대(풀 드럼·더블링 강화·악기 추가). 키업은 팝·케이팝·락·발라드만(반음~온음), 힙합 계열은 키업 대신 비트 드롭·808·드럼 추가. 진성 유지, 가성 금지.
  - **프리코러스(Pre-Chorus)**: 장르 설계에 있을 때만, 2줄.
- 인트로는 짧은 연주만(2~4마디, 최대 8초 내외). 인트로 보컬·애드리브·허밍·보컬 찹 없음.
- 보컬 기본값: solo male, full chest voice, low-mid range, doubled lead vocal. 가성·믹스보이스·런·애드리브 없음.
- 믹스 기본값: Clear Upfront Vocals, Crisp Clean Modern Mix (가사가 묻히지 않게).
- 130~140 BPM대 트렌드는 하프타임 68~76 BPM으로 적는다.
- 섹션 태그마다 악기·에너지 지시를 영어로 붙인다. 예) `[Verse 1: Minimal, bass and vocal only, low intimate tone]`, `[Bridge: Drums drop out, bass and vocal only, tension]`, `[Final Chorus: Full beat drop, 808 and guitar riff, maximum energy, doubled vocals]`
- 괄호 지문·부정 지문("no vocals")은 가사 안에 쓰지 않는다. 짧은 메타태그만.

### 장르별 곡 설계 (3분 기준 권장안, 조사로 조정)
- **힙합**: Intro → 사비(하프) → Verse 1 → 사비 → Verse 2 → 브릿지(드럼 빠짐, 베이스+보컬) → 핵사비(풀 비트, 훅 2회) → Outro — 후렴을 빨리 보여 주는 최근 힙합 흐름
- **랩**: Intro → Verse 1 → 사비 → Verse 2 → 사비 → 브릿지(비트 스위치 또는 하프타임 8마디) → 핵사비 → Outro — 벌스 중심, 브릿지에서 그루브 전환
- **트랩**: Intro → 사비(808 없이) → Verse 1 → 사비 → Verse 2 → 브릿지(808만, 하이햇 정지) → 핵사비(808 글라이드+하이햇 롤 풀) → Outro — 808 유무로 대비
- **붐뱁**: Intro(샘플 4마디) → Verse 1 → 사비 → Verse 2 → 사비 → 브릿지(샘플 필터, 드럼 브레이크) → 핵사비 → Outro(샘플) — 샘플 루프 위 벌스·훅 교대
- **락**: Intro(기타 리프) → Verse 1 → Pre-Chorus → 사비 → Verse 2 → Pre-Chorus → 사비 → 브릿지(클린 기타, 하프타임) → 핵사비(반음 키업, 크런치 기타 최대) → Outro(리프)
- **케이팝**: Intro → Verse 1 → Pre-Chorus → 사비(드롭형 훅) → Verse 2 → Pre-Chorus → 사비 → 브릿지(스트립다운, 악기 거의 정지) → 핵사비(키업+풀 편곡) → Outro(훅 리프만)
- **팝**: Intro → Verse 1 → Pre-Chorus → 사비 → Verse 2 → 사비 → 브릿지 → 핵사비(반음 키업) → Outro — 짧고 깔끔하게
- **로파이**: Intro(로즈) → Verse 1 → 사비 → Verse 2 → 사비 → 브릿지(로즈+보컬만) → 핵사비(드럼·베이스 풀, 키업 없이 레이어만 추가) → Outro(로즈)
- **발라드**: Intro(피아노) → Verse 1 → Pre-Chorus → 사비 → Verse 2 → 사비 → 브릿지(스트링 빌드업) → 핵사비(온음 키업, 진성 유지) → Outro(피아노)

### Style of Music 작성 순서 (영어, 쉼표 구분)
`BPM, Key, 장르·서브장르, 드럼, 베이스, 대표 악기 2~3개, 보컬 설정, 보컬 전달 방식, 믹스, 구조 지시, English lyrics`

### Exclude Styles 작성법
- 지난 곡들의 불만 목록을 통째로 붙이지 않는다.
- 이번 장르가 잘못 흘러가기 쉬운 방향 + 조사에서 안 맞는다고 본 요소만 짧게(6~12개).

### 장르별 출발값 (조사 결과로 덮어쓴다)
- **힙합**: 88~96 BPM, 단조. 실수 방향 → 옛날 가요풍, 과한 오토튠, 애드리브 과다
- **락**: 120~150 BPM(또는 하프타임), 클린·크런치 기타. 실수 방향 → 메탈, 애니 OST, 중동풍 스케일, 걸걸한 보컬
- **케이팝**: 100~124 BPM, 훅 중심, 장르 혼합. 실수 방향 → 옛 아이돌 댄스, 유치한 챈트(나나나), 과한 하모니
- **팝**: 100~120 BPM, 깔끔한 훅. 실수 방향 → 스타디움 리버브, 과한 밝음, 디스코 클리셰
- **로파이**: 70~90 BPM, 로즈·재지 코드 허용. 실수 방향 → 바이닐 노이즈가 가사를 덮음, 축음기 질감, 보컬 묻힘 (로파이 질감은 악기에만, 보컬은 선명하게)
- **발라드**: 60~80 BPM, 피아노·스트링. 실수 방향 → 가성 고음 클라이맥스, 꺾기, 뮤지컬풍
- **랩**: 85~100 BPM, 정박 랩 중심. 실수 방향 → 혀 꼬이는 속사포, 하이프맨, 과한 애드리브
- **트랩**: 68~76 하프타임(=136~152), 808 글라이드, 하이햇 롤. 실수 방향 → 과한 애드리브(yeah), 저음 뭉개짐, 하드 레이지 과잉
- **붐뱁**: 86~94 BPM, 스윙 드럼·샘플 찹·업라이트 베이스. 실수 방향 → 재즈 라운지, 올드스쿨 패러디, 지글거리는 테이프 노이즈 과다

## 3단계. 주제와 가사 만들기

### 주제 정하기
- 트렌드 시트의 "가사 테마"를 출발점으로, **우리 대화 내용(회사·퇴근·인스타 등)은 쓰지 않는다.**
- 4대 원전 틀로 오리지널 이야기를 만든다.
  - M1 기획의 정석: 누가 듣나(WHO), 그 사람이 왜 이 곡을 틀까(Why).
  - M2 하버드 OREO: 사비 첫 줄 = 주장(O), 1절 = 이유(R), 2절·브릿지 = 증거 장면(E), 핵사비 마지막 줄·아웃트로 = 새 말로 재강조(O).
  - M3 픽사 척추: 옛날에 / 매일 / 그러던 어느 날 / 그래서 / 마침내 / 그날 이후.
  - M4 스토리 설계자: 화자의 잘못된 믿음 하나를 2절에서 깬다. 감정 단어 대신 행동과 반응.
- 주제 후보 2개를 내고 하나를 추천한다(이유 한 줄).

### 가사 규칙 (영어 100%)
- 사비 첫 줄 = 4~7단어 훅. 먼저 정하고 나머지를 맞춘다. 1곡 1메시지. 사비 4줄.
- 브릿지 4줄, 줄당 4~7단어. 사비·벌스에 없던 새 장면으로 반전(잘못된 믿음이 깨지는 순간).
- 핵사비 = 사비 4줄 기본, 마지막 줄만 새 말로 바꿔 결론을 찍는다(OREO의 마지막 O). 훅 첫 줄은 절대 바꾸지 않는다.
- 프리코러스(있을 때) 2줄, 사비로 끌어올리는 짧은 문장.
- Verse 1·Verse 2 각 6줄, 줄당 5~7단어, 두 절 리듬 대칭. 1절 = 지금 상황, 2절 = 태도 심화·반전.
- 2줄/4줄 단위로 끝소리 라임. 사비·핵사비 끝음은 열린 모음.
- 어른스럽고 시크한 태도, 담백. 상황을 장면과 행동으로 보여준다.
  - 좋은 예: 힘·지위가 보이는 이미지(작은 글씨로 박힌 이름, 문을 잡아 주는 손, 갑자기 조용해지는 방, 드는 잔), 이중 의미, 무표정한 농담
  - 나쁜 예: 생활 소품 나열(라면·냉장고·영수증), 자기 위로("it's okay", "you did enough"), 귀여운 권유
- AI 상투어 금지: neon, shadow, midnight, dark, static, echo, fade 등 (`_suno_brief.md` 목록 전체)
- 한 줄 은유 하나로 끝낸다. 두세 겹 은유 금지.
- 발음하기 쉬운 단어. 혀 꼬이는 자음 연속, 닫힌 소리로 끝나는 후렴 단어 피하기.

## 4단계. 출력 형식 (장르마다, 휴대폰에서 복사하기 쉽게)

1. **트렌드 요약** (세로 목록 5~8줄, 각 줄에 출처)
2. **주제 후보 2개** + 추천 1개와 이유
3. **곡 제목** 1~2개
3-1. **곡 설계표**: 섹션 순서 · 섹션별 마디 수 · 예상 시간(초) · 에너지(1~10) · 장르 설계 선택 이유 한 줄
4. **화자 설정** 한 줄
5~8. **Suno 입력** — Suno 만들기 탭(suno.com/create) 필드 순서 그대로, 필드마다 따로 복사할 수 있게
   - ① 제목 (Song Title): 한 줄
   - ② 가사 (Lyrics): 코드블록 하나 (메타태그 포함)
   - ③ 스타일 (Styles): 코드블록, 영어, 쉼표 구분, 1,000자 이내(권장 200~450자)
   - ④ 제외 스타일 (Exclude Styles): 코드블록, 6~12개
   - ⑤ 기이함 (Weirdness): % 값
   - ⑥ 스타일 영향 (Style Influence): % 값
   - ⑦ 다양성: % 값 (낮을수록 생성 결과가 일정하게 나온다고 보고 장르별로 조정)
   - 이유 한 줄 (⑤~⑦을 왜 그렇게 잡았는지). 보컬 성별 옵션이 있으면 Male.
9. **자체 검수표**
   - 3분 내외(2:50~3:15)인가 (마디 수 × 240 ÷ BPM, 스크립트로 계산)
   - 사비·브릿지·핵사비가 모두 있고, 핵사비가 가장 센가(훅 첫 줄 동일, 편곡 최대)
   - 실존 이름·기존 가사·훅 단어를 가져오지 않았는가
   - 금지어가 없는가
   - Verse 6줄 대칭, 줄당 5~7단어인가 (스크립트로 세어 확인)
   - Exclude가 이번 장르에 맞게 짧은가
   - 사용자가 지정한 보컬·무드가 빠지지 않았는가
   - 고칠 점 2개

전부 끝나면 마지막에 장르별 한 줄 요약(장르 · 제목 · BPM · 한 줄 무드)을 붙인다.
