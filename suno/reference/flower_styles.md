# 레퍼런스 분석: Johnny Stimson – "Flower" (2019) → Suno 스타일 3개

> 영상: https://youtu.be/EcaUV-mrKEA (가사 자막 업로드)
> 오디오: 유튜브가 이 서버를 봇으로 판단해 다운로드를 막아 직접 측정하지 못함. 아래 수치는 BPM·키 데이터베이스와 리뷰 기사 기준.

## 분석
- 발매: 2019-04-05 싱글, 길이 2:53 (Tunebat)
- 템포·박자: 197 BPM, 3/4로 표기됨. 하프타임으로 읽으면 99 BPM (SongBPM, Musicstax)
  - 3/4 표기는 셋잇단으로 흔들리는 그루브를 기계가 그렇게 읽었을 가능성이 큼. 체감은 99 BPM 안팎의 느린 스윙으로 추정(직접 확인 못 함)
- 키: C minor, Camelot 5A (세 사이트 일치) / 음량 약 -7.7 dB (Musicstax)
- 사운드: 벨벳 같은 보컬, 연기 낀 듯한 공간감, 관능적인 무드. 소울 쪽 팝이고 "덜어낼수록 좋다"는 절제가 핵심 (EarMilk 2019)
- 주제: 완벽한 순간에 머물고 싶은 마음. 꽃이 피고 지는 이미지에서 출발 (HollywoodLife 2019)
- 보컬: 원곡은 부드러운 고음 위주로 알려져 있지만, 기본값(저~중음 진성, 가성 금지)에 맞춰 진성으로 옮김
- 가사·멜로디는 가져오지 않음. 실존 이름은 스타일에 넣지 않음
