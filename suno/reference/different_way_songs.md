## 분석
- 발매 2017-09-21, 길이 3:18 (Wikipedia)
- 템포 105 BPM, 키 F minor (DJ 트랙 데이터베이스). AcousticBrainz는 멜로디 기준 C# major, 코드 기준 F minor로 봄 → F minor 기준으로 씀

- 반응: "지붕 열고 드라이브하고 싶어지는 곡" (Complex), 바이럴 영상과 수천만 스트리밍 (EarMilk 2017)
