# 레퍼런스 곡 분석 + 수노 제작 가이드

> 분석 대상: 사용자가 보낸 `D.m4a` (3분 51초)
> 원곡 가사 전문은 저작권 때문에 이 문서에 싣지 않았어요. 구조, 주제, 표현 방식만 분석했고, 아래 가사는 새로 쓴 창작 가사예요.

## 1. 사운드 분석 (Essentia·librosa 측정값)

| 항목 | 결과 |
|---|---|
| 템포 | **85 BPM** (느긋한 미디엄 템포) |
| 박자 | 4/4 |
| 키 | C major로 측정됐지만, 가장 많이 나오는 코드가 **Am**이라 실제 느낌은 **A minor 쪽의 쓸쓸한 장조** |
| 코드 흐름 | **C → Am → G** 반복이 뼈대. 중간중간 **Gm, Cm, E♭**처럼 장조에서 벗어난 코드가 들어가서 쌉쌀한 느낌을 만듦 |
| 장르 경향 | 트립합, 다운템포, 붐뱁, 앰비언트 (모델 점수가 낮고 고르게 퍼져 있어서 **한국식 얼터너티브 R&B + 랩** 계열로 해석) |
| 악기 | 베이스, **일렉 기타**, 드럼, 신스, 키보드·피아노, 드럼머신 |
| 분위기 | dark, film, relaxing, deep, love, dream (밤, 영화 같은, 몽환) |
| 보컬 | 노래는 여성 쪽으로 기울지만 확실하지 않음 (0.62). 중후반에 **랩 벌스**가 있음 |
| 보컬 음역 | 대략 **E3 ~ A♯4** (중음역 위주, 고음으로 내지르지 않음) |
| 음량 흐름 | 인트로는 아주 작게 시작 → 0:50부터 커짐 → 3:26부터 줄어들며 끝남 |

## 2. 곡 구조 (보컬을 분리해서 받아쓴 결과와 소리 분석을 합쳐서 정리)

| 시간 | 구간 | 특징 |
|---|---|---|
| 0:00~0:28 | **인트로** | 보컬 없이 반주만, 조용하게 |
| 0:28~0:50 | **Verse 1** | 일상 장면 묘사 (침대, 창가, TV, 배고픔인지 허전함인지) |
| 0:50~1:11 | **Pre-Chorus** | 같은 단어를 3번 반복하는 짧은 구절 + 영어 추임새 (baby) |
| 1:11~1:25 | **Chorus 1** | 핵심 주제를 담은 짧은 후렴. "채워지지 않는다"는 공허함 |
| 1:25~1:50 | **Verse 2** | 달, 밤 이미지. 영어 한 줄 (I'm awake) |
| 1:50~2:06 | **빌드업** | "~까지"로 장면을 나열하며 감정을 끌어올림 |
| 2:06~2:28 | **Chorus 2** | 한 단어를 4번 연달아 반복하는 변형 후렴 |
| 2:28~3:00 | **Rap Verse** | 2초에 한 줄꼴로 빽빽한 랩. 보름달, "하나였던 우리"와 지금의 대비 |
| 3:00~3:26 | **Final Chorus** | 마지막 후렴 |
| 3:26~3:51 | **아웃트로** | 영어 가사로 잔잔하게 마무리 (stars, moon) |

## 3. 가사 스타일 분석

- **주제:** 이별 후 혼자 보내는 밤의 그리움과 공허함
- **핵심 이미지:** 밤, 달(보름달), 별. 비어 있는 방과 마음을 "채운다"는 동사로 계속 이어감
- **표현 방식:**
  - 거창한 말 대신 **아주 사소한 일상**(침대, TV, 멍 때리기)으로 감정을 보여줌
  - 후렴은 **짧은 문장 + 반복**. 같은 단어를 3~4번 연달아 써서 귀에 꽂히게 함
  - 줄 끝을 **"-네", "-텐데"**로 맞춰 라임을 만듦
  - 영어는 짧은 추임새 정도로만 섞음 (baby, I'm awake, yeah)
  - 랩 벌스에서 **"하나였던 우리 vs 각자인 지금"** 대비로 이야기를 정리함

## 4. 수노 입력값

### Style (스타일 칸)
```
Korean alternative R&B, lo-fi trip-hop groove, 85 BPM, A minor, mellow clean electric guitar, warm deep bass, soft synth pads, dusty boom bap drums, intimate airy female vocal, laid-back male rap verse, late night, moonlight, longing, bittersweet, dreamy, cinematic
```

### Exclude Styles (제외 칸)
```
EDM, trap hi-hats, heavy distortion, screaming, upbeat pop, autotune
```

### Title (제목 예시)
`반쪽 달` / `Half Moon`

## 6. 수노에서 잘 만드는 팁

1. 처음엔 **Style 칸을 그대로** 넣고 2~4곡 뽑은 뒤 가장 비슷한 곡을 고르기
2. 랩이 노래처럼 나오면 `[Rap Verse]` 아래 첫 줄에 `(male rap, spoken flow)`를 추가하기
3. 후렴이 약하면 `[Chorus]` 옆에 `(catchy, layered harmonies)`를 붙이기
4. 마음에 드는 곡은 **Extend**로 이어 붙이거나 **Cover**로 다른 보컬 톤 시도하기
5. 가수 이름이나 원곡 제목은 수노에 넣지 않기

## 참고: 분석의 한계

- 가사 받아쓰기는 보컬만 분리한 뒤 Whisper로 했지만, 노래라서 틀린 단어가 많았어요. 구조와 주제 파악용으로만 썼어요.
- 장르 점수는 모델이 한국 R&B를 잘 모르기 때문에 낮게 나와요. 그래서 측정값(템포, 악기, 코드)과 받아쓴 가사 구조를 합쳐서 해석했어요.
- 보컬 성별과 음역은 확실하지 않아요. 직접 들어보고 Style의 `female vocal`과 `male rap` 부분을 고쳐 쓰세요.
