# 스레드 2주 플랜: 탄성코트 + 일상

탄성코트 시공하는 사람의 일상과 노하우를 함께 보여 주는 계정을 가정한 플랜입니다.

## 계정 방향

- **콘셉트:** "베란다 곰팡이 잡는 사람의 일상"
- **비율:** 탄성코트 노하우 50% · 현장 이야기 30% · 순수 일상 20%
- **말투:** 반말 섞인 편한 말투, 짧은 문장, 줄바꿈 많이
- **올리는 횟수:** 하루 1~2개 (오전 8시쯤, 밤 9시쯤)
- **프로필 소개 예시**
  ```
  베란다 곰팡이 잡는 사람
  탄성코트 시공 N년차 · 현장 이야기 매일 올림
  견적·상담은 DM
  ```

## 스레드에서 잘 되는 규칙

1. **첫 줄이 전부입니다.** 첫 줄만 보고 '더 보기'를 누를지 정합니다.
2. **질문으로 끝내세요.** 스레드는 댓글이 많을수록 더 멀리 퍼집니다.
3. **사진 1장을 붙이면 좋습니다.** 시공 전후, 현장, 도구 사진이면 충분합니다.
4. **댓글에는 1시간 안에 답하세요.** 처음 1시간의 반응이 노출을 좌우합니다.
5. **홍보는 7개 중 1개만** 하세요. 나머지는 도움이 되거나 재미있는 글로 채웁니다.

## 1주차: "이 사람 누구지?" 알리기

### 1일차 (월) · 자기소개
```
베란다 곰팡이 잡는 일 하는 사람입니다.

하루에 집 2~3곳 다니면서
곰팡이 핀 벽 보고 한숨 쉬는 게 일이에요.

여기엔 현장에서 본 것들,
집에서 바로 써먹을 수 있는 거 올려볼게요.

혹시 지금 베란다 벽 상태 어때요?
```
📷 현장에서 찍은 내 작업복이나 도구 사진

### 2일차 (화) · 노하우
```
베란다 곰팡이, 락스로 닦으면 끝일까요?

아니요. 2주 뒤에 다시 올라와요.

곰팡이는 벽 속까지 뿌리를 내려서
겉만 닦으면 잠깐 하얘졌다가 또 핍니다.

진짜 잡으려면
1. 곰팡이 제거
2. 완전히 말리기
3. 방수·방곰팡이 코팅
이 순서가 지켜져야 해요.

락스로 몇 번째 닦고 계세요?
```

### 3일차 (수) · 현장 이야기
```
오늘 간 집, 베란다 문 열자마자 냄새로 알았어요.

벽 아래쪽이 까맣게 올라와 있었는데
어머님이 "매주 닦는데도 이래요" 하시더라고요.

닦는 게 문제가 아니라
결로(벽에 물 맺히는 거)가 원인이었어요.

이런 집 생각보다 정말 많습니다.
```
📷 시공 전 사진 (집주인 허락 받고, 집 안 알아볼 수 있게)

### 4일차 (목) · 일상
```
현장 3곳 끝나고 먹는 국밥이 제일 맛있음.

오늘은 순대국.
다들 일 끝나고 먹는 최애 메뉴 뭐예요?
```
📷 국밥 사진

### 5일차 (금) · 노하우 (저장 유도)
```
탄성코트 하기 전에 꼭 물어봐야 할 3가지
(저장해두세요)

1. 곰팡이 제거 작업이 포함인가요?
2. 몇 번 칠하나요? (보통 2회 이상)
3. 하자 생기면 A/S 기간이 얼마예요?

이거 대답 흐리는 업체는 한 번 더 생각해보세요.
```

### 6일차 (토) · 전후 비교
```
같은 베란다 맞습니다.

왼쪽: 어제
오른쪽: 오늘

이 집 사장님이 제일 좋아하신 건
"이제 빨래 널어도 냄새 안 나겠다"였어요.
```
📷 전후 사진 2장

### 7일차 (일) · 소통
```
주말이라 쉬는 날.

궁금한 거 아무거나 물어보세요.
베란다, 곰팡이, 결로, 탄성코트, 뭐든요.
아는 만큼 다 답해드림.
```

## 2주차: "믿을 만한 사람" 되기

### 8일차 (월) · 오해 바로잡기
```
"탄성코트 하면 곰팡이 평생 안 핀다"

이거 반은 맞고 반은 틀려요.

코팅이 곰팡이를 막아주는 건 맞는데
환기를 아예 안 하면 언젠가 다시 핍니다.

시공 후에도
하루 10분 창문 열기는 꼭 하세요.
```

### 9일차 (화) · 현장 에피소드
```
오늘 시공하는데
집에 있던 강아지가 4시간 내내 저만 쳐다봄.

감시당하면서 일한 건 처음이에요.
그래도 덕분에 평소보다 꼼꼼하게 칠한 듯.
```
📷 강아지 사진 (허락 받고)

### 10일차 (수) · 숫자로 신뢰
```
이번 달 다닌 집 세어봤어요.

- 곰팡이 원인이 결로: 대부분
- 이전에 셀프로 페인트 칠했던 집: 꽤 많음
- 락스만 쓰다 온 집: 거의 다

셀프로 칠했다가 더 심해진 경우도 있어서
그 얘기는 내일 따로 할게요.
```
(실제로 센 숫자로 바꿔서 쓰세요. 숫자를 지어내면 안 됩니다.)

### 11일차 (목) · 셀프 vs 시공
```
베란다 셀프 페인트 vs 탄성코트 시공

셀프 페인트
- 싸다
- 곰팡이 제거 안 하고 칠하면 금방 들뜸

탄성코트 시공
- 비용이 든다
- 제거 → 건조 → 코팅까지 한 번에

솔직히 곰팡이가 거의 없으면 셀프도 괜찮아요.
이미 까맣게 올라왔으면 제거부터 제대로 해야 합니다.

셀프로 해보신 분 후기 궁금해요.
```

### 12일차 (금) · 일상
```
요즘 제일 행복한 순간:
현장 끝나고 차에서 시동 걸기 전 5분.

아무것도 안 하고 그냥 앉아있음.

여러분은 하루 중 언제가 제일 좋아요?
```

### 13일차 (토) · 고객 후기
```
2주 전에 시공한 집에서 연락이 왔어요.

"장마 왔는데도 벽이 멀쩡해요"

이 일 하면서 제일 기분 좋은 문자.
```
📷 문자 캡처 (이름·번호 가리고, 허락 받고)

### 14일차 (일) · 상담 안내 (이번 주 유일한 홍보)
```
2주 동안 봐주셔서 감사해요.

베란다 사진 DM으로 보내주시면
곰팡이 상태랑 셀프로 될지, 시공이 필요할지
솔직하게 봐드릴게요.

무료고, 시공 안 하셔도 됩니다.
```

- 글 올리고 1시간 안에 댓글 답하기
- 인테리어·집꾸미기·자취·신혼집 글에 진짜 도움 되는 댓글 3~5개 달기
- "곰팡이", "결로", "베란다" 검색해서 고민 글에 답해주기 (홍보 말고 조언만)

## 2주 뒤 확인할 것

- 조회수·댓글이 가장 많았던 글 3개 → 3주차에 같은 유형으로 더 올리기
- 반응 없던 유형은 줄이기
- DM 문의가 몇 건 왔는지 세기

## 지킬 것

- 고객 집 사진·문자는 꼭 허락 받고, 주소나 얼굴이 보이지 않게
- 숫자와 후기는 실제 있는 것만 쓰기
- "평생 보장", "100% 안 핀다" 같은 과장은 하지 않기
