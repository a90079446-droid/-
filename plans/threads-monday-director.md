# 월요일 알람 글 · 감독 버전

## 원본 (설명이 중심)
알람 시각을 쭉 나열하고 "자영업인데 지각하면 혼남"으로 끝나는 글. 웃기긴 한데 **장면이 없고 설명만 있음**.

## 감독 버전 (장면이 중심)

```
1/3
06:30
알람이 울린다.
손만 이불 밖으로 나가서 폰을 찾는다. 눈은 안 뜸.
끈다.

06:37
또 울린다.
이번엔 손이 폰 대신 리모컨을 집음.
TV가 켜진다.

"오늘 전국 대부분 지역에 비가…"
```
```
2/3
눈이 번쩍 뜨임.

알람 3개는 무시하는 몸이
'비' 한 글자에 앉아서 창문부터 확인함ㅋㅋ

[9시에 ○○아파트 베란다 약속] 잡혀 있는데
비 오면 일정이 통째로 날아가거든.

커튼 열었더니
맑음.

뉴스는 내일 날씨 얘기였음.
```
```
3/3
06:58
잠은 이미 다 깼고
알람을 끈 건 나 혼자였음.

자영업이라 출근 시간 내 맘대로일 줄 알았는데
고객님은 9시에 현관문 열고 기다리심.
사장은 지각해도 혼나는 건 똑같음ㅋㅋ

너네는 알람 말고 뭐에 눈이 번쩍 뜨임?
나는 '비'.
```

## 감독이 손본 곳

| 기법 | 어디에 썼나 |
|---|---|
| **컷 편집** | 시각(06:30 → 06:37 → 06:58)이 장면 전환 역할을 함. 설명 없이 시간이 흐름 |
| **보여주기** | "자꾸 끔" 대신 "손만 이불 밖으로 나가서 폰을 찾는다. 눈은 안 뜸" |
| **작은 사고** | 폰 대신 리모컨을 집어서 TV가 켜짐. 이게 이야기를 움직이는 계기 |
| **반전** | 못 일어나던 사람이 '비' 한 글자에 벌떡 일어남 |
| **한 번 더 비틀기** | 창문을 열어 보니 맑음. 뉴스는 내일 얘기 (허탈한 웃음) |
| **여운 있는 마무리** | "알람을 끈 건 나 혼자였음"으로 장면을 닫고, 질문은 맨 끝에 한 번만 |

## 올리기 전 확인
- `[ ]` 부분(약속 장소 등)은 실제 겪은 걸로 바꿔 줘. 비 때문에 일정이 밀리는 직업이라는 건 실제와 같을 때만 써.
- 리모컨 사건이 실제로 없었다면 "폰 대신 다른 걸 집었다"처럼 네가 겪은 비슷한 일로 바꿔. 지어낸 사건을 진짜인 척 쓰지 않기.
