📘 탄성코트 시공 블로그 자동 생성기

이 폴더는 GitHub Pages용입니다.

📦 구성:
- blog_generator.html → 웹사이트 메인 페이지
- favicon.ico → 사이트 아이콘
- README.txt → 설명서

📋 업로드 방법:
1. https://github.com 에 로그인
2. 새 저장소(repository) 생성 (예: blog-generator)
3. blog_generator.html 과 favicon.ico, README.txt 업로드
4. Settings → Pages → Source: “Deploy from a branch” 선택
5. Branch: “main” / “(root)” 선택 후 Save
6. 잠시 기다리면 링크가 생성됩니다:
   👉 https://username.github.io/blog-generator/

이 링크로 접속하면 웹사이트처럼 실행됩니다.
