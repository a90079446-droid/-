## 다시 만들기

```bash
sudo apt-get install -y fonts-noto-cjk ffmpeg
pip install numpy scipy pillow
python3 make_video.py            # 전체 영상
python3 make_video.py --stills   # 장면별 미리보기 이미지 (stills/)
python3 make_video.py --scale 0.5  # 960×540 빠른 렌더
```

자막 문구와 장면 길이는 `make_video.py` 상단의 `SCENES` 목록에서 바로 고칠 수 있습니다.
